# 文件上传与导入（仅前端）

## 范围边界

1. **包含**：**R-FILE-01**——发起请求前的类型与大小校验、用户可见超限提示。
2. **不包含**：服务端解析 Excel、空模板、业务空值等后端逻辑结论。

## 覆盖规则 ID

**R-FILE-01**（见 [RULE-CATALOG.md](../verifying-ui-functional-rules/RULE-CATALOG.md)）。  
模板解析、空行、表头校验、业务字段错误等**服务端行为**不在本 skill 检测范围内。

## 命题（R-FILE-01）

在**发起上传前**（`beforeUpload` / `before-upload` / 自定义选择后上传函数首段），必须能拦截明显非法文件：

- **类型**：扩展名白名单、或与 `accept` 一致的校验；若存在**原生** `<input type="file">`，应对 `accept` 与脚本校验同时核对。
- **大小**：上限为**命名常量**（或清晰字面量），超限有**用户可见提示**。

## UI 形态（须覆盖项目实际使用的库）

| 序号 | 形态 | 典型信号 |
|:----:|------|----------|
| 1 | **Ant Design Vue** | `Upload` / `UploadDragger`、`beforeUpload`、`customRequest`、`accept` |
| 2 | **Element Plus** | `el-upload`、`before-upload`、`accept`、`on-change` 内校验 |
| 3 | **原生** | `<input type="file" accept="...">`、在 `change` 中读取 `file.type` / `file.name` / `file.size` |

## 观测清单

- [ ] `accept`（若有）与代码中的类型判断**一致**；扩展名可伪造时，前端仍应做到**力所能及**的校验（后缀 + `size`），并在报告中写明「未做魔数/MIME 字节校验」若代码中确实没有。
- [ ] 分片/断点上传：若存在，每片与总大小、失败重试的**前端**提示是否可感知（不要求测实际网速）。
- [ ] 多入口上传（弹窗内、表格行内、导入按钮）是否各自有校验，避免只封一条路径。

## 输出规则（对用户报告）

1. **不输出 PASS 明细**：已满足 **R-FILE-01**、无需跟进的入口**不要**逐条写入报告正文，**不**占用「明细」有序列表篇幅。
2. **只输出缺口明细**（本专项下等同于 **FAIL** 或与 FAIL 等价的需跟进项）：以 **有序编号**（`1.`、`2.`、…）逐条列出；**每条单行**，字段顺序须为 **`{序号}. FAIL [{仓库相对路径:行号}] 判定原因：{一句话}`**（**UNKNOWN** 等用时将 **FAIL** 换成对应标签）；「判定原因」内写简短原因 + **缺何种信号**（如：accept 与脚本不一致、无类型白名单/后缀校验、无大小上限或无常量、无用户可见超限提示、多入口未覆盖等）；可含类型白名单来源、大小常量、UI 库或原生。**不得**省略序号。**不要**要求引用后端控制器、SQL 或接口错误码；**不要**输出「后端应返回行号」类清单。
3. **UNKNOWN / PARTIAL**：**不得**单独用 PASS 充数；须输出时**并入**上述有序列表并占用序号，或于文末**一行**汇总「待查 N 处」，仍**不**展开 PASS。
4. **可选一句总括**：仅在需要时于报告**末尾**加一句（可不编号），例如「其余已检上传入口未见需列入 R-FILE-01 的缺口」，**不得**展开 PASS 列表。

## 与总控 `verifying-ui-functional-rules` 的关系

1. 用户 **`@` 总控**或要求按 **RULE-CATALOG** 整体验证时：须遵守总控的总览表（「风险条数」与下方各章明细条数一致），以及以 `- **明细**：` 起头的有序编号列表等输出约定；**R-FILE-01 子项在明细中只列缺口**，且**每条须带序号**；不在总控明细里堆 PASS。
2. 用户**仅 `@` 本专项**时：正文**只写缺口明细**（与上节「输出规则」第 2 条一致），每条 **须带序号**；单行顺序与总控 [verifying-ui-functional-rules](../verifying-ui-functional-rules/SKILL.md)「统一明细行格式」一致：**FAIL → [路径:行号] → 判定原因：**。
